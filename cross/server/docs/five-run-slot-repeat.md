# Пять заполнений: повтор ответов по координатам

Дата: 12 октября 2026. Текущий рабочий CSP+MAC с включённым перемешиванием probe.
По пять прогонов наборов выпуска 77 (56 шаблонов) и 78 (96 шаблонов).
Словарь, геометрия, историческая статистика и настройки зафиксированы на пять
прогонов; состояние использованных слов очищается перед каждым новым прогоном.
Выпуски, задания и счётчики использования не изменяются.

Слот — один и тот же шаблон, координата старта, направление и длина ответа.
В замороженной геометрии это соответствует стабильному `slotId`, по которому
упорядочены ответы в отчёте. Одинаковое слово в другом слоте не считается
повтором по координатам. Определения и картинки не сравниваются.

Все **760/760** заполнений успешны. Каждый набор сравнивается по всем десяти
парам прогонов: 1–2, 1–3, 1–4, 1–5, 2–3, 2–4, 2–5, 3–4, 3–5, 4–5.

Для каждой пары: `совпавшие ответы в тех же слотах / число слотов × 100%`.
Среднее считается по десяти парам, а не как доля полностью одинаковых сеток.

## Сколько разных ответов получил один слот за пять запусков

| Разных слов в слоте | Набор 56: слотов | Набор 96: слотов |
| --- | ---: | ---: |
| 1 — одно и то же слово во всех пяти | 410 (20.14%) | 270 (4.04%) |
| 2 | 318 | 202 |
| 3 | 214 | 284 |
| 4 | 319 | 704 |
| 5 — каждый раз другой ответ | 775 (38.06%) | 5226 (78.16%) |

Хотя бы один повтор ответа в пяти запусках встретился в 61.94% / 21.84% слотов
соответственно. Это другой показатель, чем средние попарные 32.24% / 7.71%:
он отвечает на вопрос, повторялось ли слово хотя бы дважды за все пять попыток.
Пять совпадений не доказывают, что ответ логически единственный или вынужденный:
также могут влиять ранжирование и предпочтения балансировки.

Одна из 56 сеток полностью одинакова во всех пяти запусках; 46 из 56 получили
пять разных полных заполнений. Все 96 больших сеток получили пять разных
полных заполнений, несмотря на отдельные совпадающие ответы внутри них.

## Скорость, баланс и повторы внутри выпуска

| Набор | Чистый поиск по прогонам, с | Средняя историческая частота слов по прогонам |
| --- | --- | --- |
| 56 | 0.849 / 0.849 / 0.855 / 0.850 / 0.859 | 74.71 / 75.20 / 74.51 / 74.68 / 74.68 |
| 96 | 4.235 / 5.663 / 4.529 / 7.142 / 3.839 | 73.50 / 73.62 / 73.67 / 73.78 / 73.67 |

Внутри отдельной сетки повторов нет. Между шаблонами одного выпуска на наборе
56 повторов не было; на наборе 96 дополнительные повторные использования по
прогонам — **9 / 0 / 0 / 4 / 0**, после разрешённого fallback. Это не те же
повторы, которые измеряются выше между отдельными запусками по координатам.

Результат — пять измеренных прогонов, не гарантия такого процента в будущем.
Тест не исключает ответы прошлых прогонов из словаря и не учитывает увеличение
статистики после реальной финализации выпуска: счётчики специально фиксированы.

## Воспроизведение

```sh
pnpm run test:fill-batch-solver-comparison /private/tmp/megacross-repeat-five.json --production-defaults --engine=csp --repeats=5
```

Исходный JSON содержит все 760 попыток и 20 попарных сравнений двух наборов.
Метрики рассчитаны из слов, упорядоченных по `slotId`; для каждого заполнения
проверяются полное число ответов, принадлежность словарю и внутрисеточная
уникальность. Ни одна сетка из знаменателей в этом тесте не исключена.
